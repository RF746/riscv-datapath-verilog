# Security Policy

## Scope

This repository is an educational RTL example. It is not intended to enforce a
security boundary or to control safety-critical equipment. Its simplified
memory interface, unsupported instruction classes, and documented architectural
limitations should be considered when reusing the design.

## Reporting a vulnerability

Please report a suspected security issue through GitHub's private vulnerability
reporting or security-advisory feature for this repository. Include:

- the affected module and revision;
- a minimal reproducer or instruction sequence;
- the observed behavior and the expected behavior; and
- any suggested mitigation, if known.

Please do not disclose an unresolved security issue in a public issue. General
functional bugs that do not have a security impact may be reported normally.

No response-time or remediation-time guarantee is provided for this educational
project.
